# Life Manager｜人生管理系统

一个无需后端、直接在浏览器本地运行的个人生活管理工作台。项目将界面、样式与逻辑集中在 `index.html` 中，打开页面即可使用。

## 功能模块

- 人生看板：聚合今日待办、每月预算、最近心情、在读进度、运动连续天数、待复习单词与近期生活动态。
- 目标管理：按长期、季度、月度层级管理目标，支持上级目标、截止日期、状态、进度和倒计时。
- 每日计划：按优先级管理待办事项，统计当天完成率。
- 记账本：记录收入与支出，汇总当月数据并生成分类图表；支持每月预算和超支联动提醒。
- 运动打卡：记录运动类型、时长和消耗，展示周热力图与连续天数。
- 心情日记：记录心情和文字，切换周/月情绪趋势，并关联近期运动、阅读、学习与完成事项。
- 读书收获：管理想看/在看/已看状态、阅读进度、读书笔记和原文画线。
- 习惯与行程：通过 7 天矩阵完成习惯打卡，同时维护旅行安排和打包清单。
- 英语学习：建立单词卡片，并按间隔复习节奏记录学习情况。
- 智能记录：用中文短句或“记账 30 晚餐”“待办 晚上8点跑步”等快捷命令记录待办、收支、运动、心情、阅读、旅行和单词。
- 周度分析：汇总各模块数据并给出可执行的回顾建议。
- 数据备份：支持导出和导入 JSON 备份。

## 移动端体验

- 底部 TabBar 固定首页、计划、AI、记账和更多入口，AI 作为中央主操作按钮。
- 人生看板会优先展示有待处理事项的数据卡片，并把零数据卡片压缩为单行空状态。
- 新增待办时使用键盘上方 Bottom Sheet，支持回车提交和优先级颜色提示。
- 待办可右滑完成、左滑延期或删除，并保留可点击的等价操作。
- 支持触感反馈、AI 入口滚动收起与安全区适配。
- 按 `Ctrl + K` 或 `⌘ + K` 可随时打开全局快捷记录。

## 桌面端体验

- 看板在中等屏幕采用双列布局，在 1200px 以上采用三列布局，避免大屏卡片过宽。
- 桌面端保留常驻侧边栏并隐藏底部 TabBar；快捷记录面板居中显示。
- 支持 `Ctrl + K` / `⌘ + K` 唤起命令框，并直接执行记账、待办、心情和运动命令。

## 运行方式

项目不需要安装依赖。可以直接双击 `index.html`，也可以在项目目录启动静态服务器：

```bash
python3 -m http.server 8080
```

随后访问 `http://localhost:8080`。

## 数据与隐私

- 所有生活记录默认保存在当前浏览器的 `localStorage` 中，不会自动上传到服务器。
- 清理浏览器网站数据会删除本地记录，请定期使用“导出备份”。
- 导入备份会覆盖当前数据；系统会在覆盖前保留一份浏览器内备份，并要求再次确认。
- 图表使用 CDN 提供的 Chart.js；离线时核心记录功能仍可使用，但图表可能无法显示。
