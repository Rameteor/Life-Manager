# Life Manager｜人生管理系统

一个无需后端、直接在浏览器本地运行的个人生活管理工作台。项目将界面、样式与逻辑集中在 `index.html` 中，打开页面即可使用。

## 功能模块

- 人生看板：聚合今日待办、每月预算、最近心情、在读进度、运动连续天数、待复习单词与近期生活动态，并按真实行动派生人生 XP、等级和成就徽章。
- 目标管理：用 OKR / SMART 管理长期、季度和月度目标，拆解量化 KR 或 Todo，一键同步到每日计划；任务完成时自动回写进度，目标完成后可归档或恢复。
- 每日计划：按优先级管理待办事项，统计当天完成率，并根据待办、收支、运动、阅读和心情实时生成自动每日小结。
- 记账本：记录收入与支出，支持总预算和分类预算、每日建议可花额度、80% / 超支预警、自我投资标识及投资消费占比。
- 运动打卡：记录运动类型、时长和消耗，展示周热力图与连续天数。
- 心情日记：记录心情、文字和触发标签，切换周/月情绪趋势，并从近 90 天记录中分析运动、熬夜与高分心情的关联线索。
- 读书收获：管理想看/在看/已看状态、阅读进度、读书笔记和原文画线。
- 习惯与行程：通过 7 天矩阵完成习惯打卡，支持连续天数、请假不断链和历史补签，同时维护旅行安排和打包清单。
- 英语学习：建立单词卡片，并通过“简单 / 模糊 / 忘记”三档反馈驱动简化 SM-2 间隔复习。
- 智能记录：用中文短句记录待办、收支、运动、心情、阅读、旅行和单词；一句话可原子写入多条记录，例如“今天打车花了 35，晚上跑步 30 分钟”。
- 周度分析：汇总各模块事实指标，并提供基于本地规则的 AI 深度点评，展示跨模块关联和下一步建议。
- 数据备份：支持导出和导入 JSON 备份，并每 7 天在当前浏览器内自动保留一个快照（最多 3 份）。

## 移动端体验

- 底部 TabBar 固定首页、计划、AI、记账和更多入口，AI 作为中央主操作按钮。
- 人生看板会优先展示有待处理事项的数据卡片，并把零数据卡片压缩为单行空状态。
- 新增待办时使用键盘上方 Bottom Sheet，支持回车提交和优先级颜色提示。
- 待办可右滑完成、左滑延期或删除，并保留可点击的等价操作。
- 支持触感反馈、AI 入口滚动收起与安全区适配。
- 按 `Ctrl + K` 或 `⌘ + K` 可随时打开全局快捷记录。

## 桌面端体验

- 看板在中等屏幕采用双列布局，在 1200px 以上采用三列布局，避免大屏卡片过宽。
- 桌面端保留常驻侧边栏并隐藏底部 TabBar；快捷记录面板居中显示。
- 支持 `Ctrl + K` / `⌘ + K` 唤起命令框，并直接执行记账、待办、心情和运动命令。

## 运行方式

项目不需要安装依赖。可以直接双击 `index.html`，也可以在项目目录启动静态服务器：

```bash
python3 -m http.server 8080
```

随后访问 `http://localhost:8080`。

## 数据与隐私

- 所有生活记录默认保存在当前浏览器的 `localStorage` 中，不会自动上传到服务器。
- 自动快照也保存在当前浏览器中；清理网站数据会同时删除记录和快照，请定期使用“一键导出 JSON”保存独立文件。
- 导入备份会覆盖当前数据；系统会在覆盖前保留一份浏览器内备份，并要求再次确认。
- “AI 深度点评”在浏览器内按本地规则计算，不会发送个人数据，也不等同于医疗、财务或心理诊断。
- 图表使用 CDN 提供的 Chart.js；离线时核心记录功能仍可使用，但图表可能无法显示。

## 技术说明

- HTML5
- CSS3 响应式布局
- 原生 JavaScript
- Chart.js 4.4.7
- 浏览器 Local Storage
